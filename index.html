💡 How paths work:
• The .esc file stores only the folder path + filename for each audio file — the file is tiny and saves instantly.
• After loading, the app opens the Confirm Audio Files wizard. For each folder, click Confirm folder and pick it. All matching files in that folder are linked at once.
• Browsers cannot silently read arbitrary paths — one click per folder is required.
