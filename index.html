📖 Music DJ Manual

🏠 Home folder system

All audio must live inside a single home folder. Click Set Folder (top-left) once to pick it. Any subfolders inside it are fine — organize as you like.

The .lgt file stores paths relative to the home folder (e.g. Halloween/scream.mp3). To restore a project, just pick the same home folder again — one click relinks everything.
